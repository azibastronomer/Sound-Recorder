Download APK
  1. Tap Download APK above. When it finishes, tap Open in the download notification (or find it in Files → Downloads).
  2. If asked, allow Chrome to install unknown apps: Settings → Apps → Chrome → Install unknown apps → Allow.
  3. Play Protect may warn it's from an unknown developer — tap Install anyway / More details → Install anyway.
  4. Once installed, open it, tap the mic, and Allow the microphone. Done 🎙️
Download button does nothing?
